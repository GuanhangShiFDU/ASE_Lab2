## 实际执行的静态检查

1. 使用 `openapi-spec-validator 0.7.2` 检查 OpenAPI 3.1 文档、引用和路径参数，9 个 operationId 无重名。
2. 使用 `jsonschema 4.25.1` 校验 18 个内嵌请求/响应/错误格式示例；9 个非法样例被拒绝：越界纬度、错误坐标系、缺 quoteId、伪造 passengerId、零版本、非 UTC 时间、负数金额、小数金额、SUCCEEDED 无结果。
3. 对两张 Mermaid 图中的请求方法、事件名与契约逐项对照；五类 ride 事件沿用原有目录及订阅边界。原事件文件没有改动。
