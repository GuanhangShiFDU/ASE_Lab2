## 单个事件的定义模板

后续按事件分小节或文件填写以下内容：

1. **名称及含义**：描述已发生的业务事实，与时序图箭头一致。
2. **触发条件**：由哪个服务在什么状态变化或业务处理完成后发布。
3. **发布方及订阅方**：订阅服务收到后承担什么职责。
4. **字段**：字段名、类型、是否必需、含义和约束，关联相应业务 ID。
5. **消息示例**：提供完整 JSON 或所选格式示例，字段与定义一致；独立示例可放到 `examples/`（定义实际事件时再创建）。
6. **处理约定**：根据选定通信方案说明版本、重复消息、顺序及失败处理；不要暗示所有消息中间件天然提供业务上的恰好一次处理。

题目提到接单已确认、乘客已上车、行程已结束等事件作为例子，实际事件集合及命名由本组流程设计确定。
